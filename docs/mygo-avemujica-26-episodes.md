## 阅读与引用约定

- 集数使用 `M01–M13`、`A01–A13`，各季独立编号；按动画揭示信息的顺序整理，回忆发生在更早时间。
- MyGO部分以用户提供的 `BanG Dream.docx` 为初始线索，重新组织并补充查证；该文档没有覆盖Ave Mujica。网络来源附在相关段落后，末尾列出使用原则。
- **日文短引**保留检索到的短句；中文为常见译法或本文译意，字幕版本可能不同，不冒充某一家发行商的官方字幕。**对白要点**是转述，不能当作逐字原话引用。没有可靠文本的集数不硬凑“名言”。不收录完整歌词。
- 本文记录动画事实。祥子与初华“已经确立秘密恋人关系”、见到某个词必定暴怒、固定冷静分钟数等，是机器人项目的同人设置或程序规则，不是动画事实。
- 若用于角色对话，只抽取当前话题所需的一两条事实；舞台宣言、冲突台词、崩溃反应都有具体场景，不是日常说话模板。观众知道的秘密，不代表每个角色都知道。

## 第一部 It's MyGO!!!!!

本季主线：爱音发起新乐队，旧成员却带着不同目的加入；首次演出的成功引爆旧伤，五人分开后通过灯的歌重新相遇，最终承认属于现在五个人的MyGO!!!!!。

### M01 羽丘の不思議ちゃん｜羽丘的不可思议女孩

**主要事件**

1. 开场呈现CRYCHIC决裂：祥子宣布退出，其他成员难以理解；睦关于自己从未觉得乐队快乐的发言进一步击碎了众人对旧团的共同认识。
2. 爱音在学年已经开始后转入羽丘。她发现组乐队是同学们共同的话题，希望借此融入环境，也希望站到显眼的位置。
3. 她先后接触祥子与灯。祥子拒绝加入；灯收集小物件、把感受写进本子，交流方式与爱音预期不同。
4. 灯把组乐队理解为很认真的长期承诺。爱音没接住她的提问，灯受到触动而离开；爱音追去解释，在RiNG与护着灯的立希起冲突。

**对白与意义**：灯的日文短引「一生、バンドしてくれる？」——“愿意和我组一辈子的乐队吗？”这不是玩笑式邀请，而是经历过失去后对稳定关系的渴望。睦的另一句关键短引是「バンド、楽しいって思ったこと一度もない」——“从来没有觉得玩乐队开心过。”这句在M03的回忆和A07的解释中还会被重新理解。[官方导语及分集页](https://anime.bang-dream.com/mygo/story/)、[编剧谈睦的发言](https://febri.jp/topics/topics-bang-dream_mygo_6_2/)

**本集结束状态**：爱音尚不清楚旧团成员为何如此敏感；灯并未完成重新开始的准备。

### M02 もう誘わない｜不再邀请

**主要事件**

1. 爱音继续在RiNG寻找成员，与爽世建立联系。爽世态度温和，成为她了解旧团的入口。
2. 得知爱音与灯同校、已经邀请过灯，爽世对新乐队明显更积极。爱音以为招募顺利，并不知道爽世想借这条线重新聚齐旧人。
3. 乐奈在店内弹吉他，展现实力，却没有按一般招募流程说明自己的打算。
4. 祥子与睦见面，希望睦不向爽世透露自己的情况；爽世持续联系祥子，信息却被阻断。
5. 立希对重新组团态度强硬，爱音意识到问题不只是缺人，开始向灯了解CRYCHIC的经历。

**对白要点〔转述〕**：爱音对立希的敌意感到莫名其妙；爽世把冲突缓和下来，却没有说明自己真正的重组目的。标题中的“不再邀请”对应受挫后的退缩，并不意味着爱音已经完全放弃。

**关系变化**：爱音与爽世的合作建立在不同期待上；爽世的体贴与她自己的愿望同时存在，不能只把她写成“温柔姐姐”或“纯粹骗子”。[官方分集页](https://anime.bang-dream.com/mygo/story/)

### M03 CRYCHIC

**主要事件**

1. 本集大量采用灯的主观视角，回到她从小难以与周围同步的感受：别人自然做到的事，她常常不理解，也不知道怎样解释自己。
2. 灯在天桥上伸手接花，祥子误以为她处于危险中，上前拉住她并擦伤。两人因此相识，灯带祥子回家处理伤口。
3. 祥子读到灯的笔记，把文字当作可以唱出的心声，并即兴配上音乐。灯第一次感到自己的表达被认真接住。
4. 祥子邀请灯，与睦、爽世、立希组成CRYCHIC。排练、共同创作《春日影》和第一次演出，让灯获得明确的归属。
5. 演出之后出现批评灯歌声的评论；祥子另有未向大家解释的变故，最终宣布退出。灯把这两件事联系起来，怀疑是自己的歌毁了乐队。

**关键文字**：灯笔记中的「人間になりたい」——“想成为人”。这是她无法融入人群时的自我表达，不是字面上的非人身份。对应即兴曲通常称为《人間になりたいうた》。[官方M03简介](https://anime.bang-dream.com/mygo/story/)、[音乐制作访谈](https://www.lisani.jp/0000234940/2/)

**不能提前混入的事实**：本集是灯所见的过去，并没有告诉灯、爽世或立希祥子家变的全貌。

### M04 一生だよ!?｜是一辈子哦！？

**主要事件**

1. 听完灯的经历，爱音尝试鼓励她再组团，爽世也希望促成重聚，但灯仍害怕重复失败。
2. 爱音无意透露祥子在羽丘，爽世因此找到祥子；祥子仍拒绝恢复旧关系，没有给出可让爽世接受的解释。
3. 爱音把几个人带到RiNG，推动她们当面说清楚。立希对祥子退出的不满，与灯对自身歌声的自责终于被区分开。
4. 灯明白立希并非讨厌自己，开始愿意再试；爽世强调遇到问题应该沟通，而不是突然离开。
5. 新团进入实际排练阶段。爱音的吉他水平远没有她最初表现得那么熟练；乐奈再次出现，带来新的变数。

**对白要点〔转述〕**：爱音惊讶于“一辈子”的重量；灯需要的是不会轻易散掉的关系，爱音则逐渐理解这不只是普通社团活动。

**关系变化**：灯迈出重新加入的第一步，但爽世心里想的依旧可能是CRYCHIC。不能把这次谈话当作所有人已经目标一致。[官方上卷集目](https://bang-dream.com/schedule/2309)、[本集讨论与场景记录](https://www.reddit.com/r/BanGDream/comments/14sc9l6)

### M05 逃げてない！｜我没有逃避！

**主要事件**

1. 乐奈对灯和她们的音乐产生兴趣，凭出色的吉他水平参与进来；她的行动随性，与其他人的焦虑形成反差。
2. RiNG出现演出机会。有人想抓住，有人觉得尚未准备好；灯怕再次失败，爱音也担心自己的水平暴露。
3. 立希指出爱音在拖延、逃避，争执让爱音离开。她碰到初中同学，对方以为她仍在英国，她的留学经历因此露出破绽。
4. 灯追上爱音，两人在水族馆谈心。爱音承认英国留学并不顺利，语言和融入问题让她回来；在新学校的积极形象也有不愿让别人看到失败的一面。
5. 两人都承认害怕，却决定不能只靠逃开解决问题，于是重新面对演出的选择。

**对白要点〔转述〕**：爱音不再只说自己“没问题”，而是把曾经逃回来的事情讲给灯听；灯没有因此否定她。

**本集重点**：爱音不只是负责社交和搞笑的人，她同样在寻找能重新开始的位置。[本集讨论与情节记录](https://www.reddit.com/r/BanGDream/comments/14ylrfp)

### M06 なんで今更｜为什么事到如今

**主要事件**

1. 演出临近，大家面对选曲、作曲与练习的实际压力。立希考虑旧曲《春日影》，爽世的反应显示她对这首歌另有顾虑。
2. 灯写下新歌词，立希负责音乐。爱音技术不足，乐奈又时来时走，立希无法把全团按自己设想推进。
3. 爽世仍尝试把睦拉回来，把当前乐队与重建CRYCHIC联系起来；睦没有顺从她的安排，祥子也得知相关消息。
4. 立希承担大量工作，越想把事情做好，越容易把自己和祥子等优秀的人比较，最终情绪失衡、缺席练习。
5. 爱音与灯去找立希，也进一步了解到乐奈的学校身份。此前被指责逃避的爱音，反过来要求立希面对问题。

**短句与场景**：「バンドやる」——乐奈简短地表示要玩乐队。她不长篇解释自己的去留，却会用实际演奏表明兴趣。立希与爱音关于“逃避”的争执形成前后呼应。[M06分集简介](https://www.tvguide.or.jp/db/anime/bang_dream/itsmygo/episode6/)、[M06剧情分析](https://lastbreath.hatenablog.com/entry/2023/07/22/044719)

### M07 今日のライブが終わっても｜即使今天的演出结束

**主要事件**

1. 第一次登台让五人都紧张。演奏起初不稳，灯声音也小；这不是一个早已默契十足的成熟乐队。
2. 祥子与睦到场。灯注意到旧友，歌声逐渐坚定，《碧天伴走》完成后得到观众回应。
3. 灯在MC中说出自己不愿让关系随着这次演出结束的心情。乐奈接着弹起《春日影》，其他成员跟上。
4. 对乐奈与爱音来说，这是共同演出的延伸；对祥子而言，却是旧日音乐由没有自己的新阵容继续演奏。祥子落泪离场，随后联系初华。
5. 后台庆祝被爽世的爆发打断：她担心这场演奏彻底破坏了挽回祥子的机会。

**核心名言**：爽世「なんで『春日影』やったの！？」——**“为什么要演奏春日影？”**说话对象是刚完成演出的队友，场景是演出后的冲突，不是祥子本人说的话。[短句与场景核对](https://www.japanese50sounds.com/en/anime/mygo/haruhikage.html)、[演出场景分析](https://news.livedoor.com/article/detail/27519883/)

**关系变化**：台上的音乐成功不等于成员的愿望相同；爽世重建旧团的目标与新团实际形成的关系正面冲突。

### M08 どうして｜为什么

**主要事件**

1. 爽世不再来练习，把精力放在联系祥子、解释《春日影》不是自己安排的事情上。
2. 灯和爱音倾向于等爽世；立希不愿让全团一直停摆。团队开始因是否等待缺席成员而分裂。
3. 祥子与初华见面，谈及之后的打算。新乐队的方向正在另一条线上形成。
4. 爽世发现单靠消息无法联系祥子，借睦找到她，当面请求恢复CRYCHIC。
5. 祥子明确拒绝。爽世从解释演出变成近乎恳求，甚至跪下；祥子认为她把自己的愿望放在最前面，离开后留下无法挽回的落差。

**名言短引**：祥子「あなた、ご自分のことばかりですのね」——常见中译“你这个人，满脑子都只想到自己呢。”爽世关于自己愿意做任何事的请求，是失去归属后的恳求，不是一般性的服从承诺。[名场面与中文译法记录](https://zh.wikipedia.org/wiki/長崎爽世)、[日文场景转录参考](https://www.bilibili.com/opus/976580640087474178)

**本集结束状态**：爽世的重建计划被祥子直接否定；但祥子仍未向她解释离开的现实原因。

### M09 解散

**主要事件**

1. 爽世的回忆交代家庭变化、搬家及进入月之森后的生活。她习惯顺应他人期待，CRYCHIC则成了自己真正珍视的归属。
2. 祥子的拒绝使她不愿继续参加当前乐队。立希主动找她，要求把立场说明白。
3. 爽世承认自己一开始想恢复CRYCHIC；爱音和乐奈并不在原定目标中。她也指出立希特别在乎灯，并非完全没有自己的偏向。
4. 立希请同学海铃临时补贝斯。海铃虽有技术与经验，却很快发现问题不在乐器空缺，单纯换人无法修补关系。
5. 爱音得知自己曾被当成过渡人选，受到伤害而离开；灯面对再次散掉的乐队陷入自责。

**对白要点〔转述〕**：爽世揭开最初招募的真实目的；爱音的问题是自己究竟是否被需要，而不仅是演奏能力够不够。

**注意**：爽世此时说出的冷酷话语是冲突中的表达，不足以证明她此前所有照顾都是虚假，也不能推导为她以后永远不在乎爱音与乐奈。[官方M09简介](https://anime.bang-dream.com/mygo/story/)、[角色与全季叙事访谈](https://natalie.mu/comic/pp/mygo03)

### M10 ずっと迷子｜一直迷路

**主要事件**

1. 灯在星象馆偶遇初华。初华关于用歌传达心情的建议，让她开始把无法当面讲清的事情带上舞台。
2. 灯在RiNG的演出空隙独自朗读、唱出自己的文字。开始不是完整乐队演出，而是她主动寻找同伴的行动。
3. 乐奈被她吸引，加入吉他伴奏，立希也重新参与。灯不再只是等待别人替她把关系修好。
4. 灯追着爱音表达：希望弹吉他的就是爱音。爱音承认自己最初想出风头，却也真的在乎这个乐队。
5. 爱音去找爽世，逼她面对自己并非毫不留恋的事实。爽世来到现场，灯拉她上台，五人演出《詩超絆》，在音乐中重新接住彼此。

**名言短引**：灯「いっしょに迷子になろう」——“一起迷路吧。”关键是承认彼此都还没有答案，而不是等谁完美了才允许留下。爱音的「見栄だよ！」可译为“就是爱慕虚荣啊！”但她已经不止于最初的动机。[灯的场景核对](https://natalie.mu/comic/pp/mygo03)、[爱音短句核对](https://japanese50sounds.com/en/anime/mygo/mie.html)

**结果**：五人重新聚齐；这是重新选择彼此，不是撤销之前所有伤害。

### M11 それでも｜即便如此

**主要事件**

1. 重聚之后才发现灯还订了三天后的演出，大家必须迅速准备曲目、衣服和实际分工。
2. 众人在爽世家一起推进歌曲。爽世不再始终维持面面俱到的外壳，队友也逐渐能接住她不那么好听的真心话。
3. 爱音处理服装与对外账号等事务，说明她的贡献不止吉他；立希的作曲、灯的文字与其他人的参与开始形成合作。
4. 乐奈的背景被揭开：她是已关闭的live house SPACE原老板都筑诗船的外孙女。她四处游走，也是在寻找新的归属。
5. “迷子”成为大家理解自己的共同词汇。她们不再拿CRYCHIC的完整样子要求眼前五个人。

**对白要点〔转述〕**：即使还会迷路、争执，也可以继续一起走；乐奈寻找的不是抽象的舞台，而是能够继续弹琴、继续待下去的地方。[乐奈背景与本集关系变化](https://natalie.mu/comic/pp/mygo03)

**结果**：重聚开始落到日常协作上。歌曲带来的和解需要由之后每次排练继续维持。

<a id="m12"></a>

### M12 It’s my go!!!!!

**主要事件**

1. 五人带着赶制完成的歌曲和衣服参加演出，准备仍然忙乱，但这次她们认可的是同一支乐队。
2. 《迷星叫》《迷路日々》《碧天伴走》等演出内容展现了新的组合；《迷路日々》也承接上一集之后共同工作的成果。
3. “迷子”的意象被转成MyGO，五个感叹号对应五个人。乐队名字终于明确下来。
4. 睦带来自己种的黄瓜祝贺。爽世追出去退还礼物，两人的结仍未解开；MyGO的重聚并没有自动修复所有旧关系。
5. 另一边，祥子与若麦谈组团，说明自己对职业活动与成员投入的要求，为Ave Mujica的正式登场铺路。

**名言短引**：祥子「残りの人生、わたくしにくださいませんか？」——“愿意把剩下的人生交给我吗？”对象是招募中的若麦，属于高投入的组团邀约，不是祥子对每个人的口头禅。[本集台词与结尾记录](https://note.com/cocoreo308/n/n60eedffc4267)、[官方歌曲收录说明](https://bang-dream.com/discographies/3457/)

<a id="m13"></a>

### M13 信じられるのは我が身ひとつ｜能相信的只有自己

**主要事件**

1. MyGO在RiNG庆祝。五人能继续相处，但没有被写成从此毫无缺点、毫无分歧的人。
2. 爽世向灯坦白：灯的文字让她感到刺痛，因为其中有她不愿面对的自己。她开始用承认真实感受代替包装自己。
3. 灯再试着向祥子靠近，祥子仍然拒绝，留下带着距离的祝福。
4. 祥子邀请睦加入新团；睦关心祥子的状况，答应陪她继续。初华、海铃、若麦也与祥子形成新的阵容。
5. Ave Mujica通过假面、舞台角色及同名歌曲亮相。台上强势而精密的Oblivionis，与演出后乘车回到困顿住处的祥子形成对照，父亲的处境成为续篇悬念。

**短句**：祥子「お幸せに」——“祝你幸福。”需要保留它在与灯疏离时的语境；不能因此断言她对灯只有恶意。[官方M13简介](https://anime.bang-dream.com/mygo/story/)

**季末状态**：MyGO成立，Ave Mujica亮相；CRYCHIC为什么散掉仍未在旧成员之间真正说清楚。祥子与初华的具体关系也不能在此直接写成已确认的恋爱关系。

## 第二部 Ave Mujica

本季主线：商业成功掩盖了团员的不同目的；揭面和曝光加重睦的压力，引发第一次解散。旧团和新团的归属争夺、睦与Mortis的冲突、初华身份的秘密陆续浮现，祥子最终重新选择承担Ave Mujica。

<a id="a01"></a>

### A01 Sub rosa.｜秘密之下

**主要事件**

1. Ave Mujica已有商业成绩。祥子强调统一舞台世界观与揭面的时机，若麦则希望利用真实身份扩大热度，两种经营方向发生冲突。
2. 祥子因父亲被警方带走而处理他的事情。回忆补充母亲去世、父亲离开丰川家，以及祥子选择陪父亲生活的经过。
3. 困顿生活与照顾父亲的责任，使她无法继续原来的校园乐队生活；这为CRYCHIC的突然决裂补上了现实背景。
4. 父亲面对女儿的优秀与自己的无力，反而伤害她。祥子不再能够靠独自照顾父亲维持原状。
5. 武道馆演出中，若麦擅自揭面并带动其他成员身份公开。祥子的计划被打乱，观众席上的爱音与爽世也看见了新团的真实阵容。

**对白要点〔转述〕**：祥子要求按既定计划活动；若麦认为曝光能够带来实际成果。父亲的拒斥是本集情绪崩溃的具体诱因，不是无缘无故的“黑化”。

**易错点**：不是整个丰川集团已经破产；“168亿日元”是土地交易诈骗相关的公司损失，不能直接写成祥子个人必须偿还的债务。[A01情节参考](https://doublesama.com/bang-dream-ave-mujica-episode-1/)、[续篇人物背景](https://en.wikipedia.org/wiki/BanG_Dream!_Ave_Mujica)、[A06出现的损失报道记录](https://note.com/srx40090/n/n60e9683e0089)

<a id="a02"></a>

### A02 Exitus acta probat.｜结果证明行为

**主要事件**

1. 揭面带来大量报道与工作机会。祥子不满若麦越过决定，但曝光已经发生，乐队必须处理后果。
2. 睦是名人之女，媒体不断把她与父母相连。若麦也看中她母亲的演艺资源，睦原本就难以表达的压力继续累积。
3. 灯关注祥子的新舞台，却觉得那个样子与自己认识的她很不一样。
4. 祥子没有稳定休息条件，初华发现后邀请她住到自己家里。两人的日常靠近在这里有具体生活原因。
5. 睦在访问中表达乐队可能持续不了多久，引发解散传闻与内部不满；巡演的演出中，她失误、僵住并崩溃。

**对白要点〔转述〕**：睦预感这支乐队撑不了多久。这是被高压推到边缘的发言，不是她已经策划了解散。有关日文措辞不在此拼接成未经核对的原话。

**结果**：成功与曝光没有改善内部沟通，反而让睦成为所有目光聚集的地方。[A02情节与采访压力](https://doublesama.com/bang-dream-ave-mujica-episode-2/)、[官方A02简介](https://anime.bang-dream.com/avemujica/story/)

<a id="a03"></a>

### A03 Quid faciam?｜我该怎么办

**主要事件**

1. 祥子用现场叙事把睦的崩溃接进舞台演出，暂时避免演出完全中断，却也让观众把真实痛苦误认成优秀表演。
2. 外界期待重现那一幕。是否迎合观众成为祥子与若麦争论的焦点，睦夹在其中，旧团破裂的恐惧被反复唤起。
3. 睦的内心舞台显现：她长期被父母的名气定义，吉他和乐队是自己争取存在感的方式。
4. 若麦试图把睦拉向自己的活动方向，睦仍顾虑祥子。祥子希望维持乐队，却未能接住睦的心理状况。
5. Mortis作为保护睦的一面走到前台。对外表现突然变得活跃、擅长表达，舞台上的“睦”与此前明显不同。

**对白要点〔转述〕**：Mortis要替无法继续承受压力的睦应对外界。核心不是睦突然变开朗，而是她以怎样的代价继续站在台上。

**叙事边界**：内心剧场是表现手法，不是现实里出现了另一个有独立身体的女孩。[A03事件参考](https://doublesama.com/bang-dream-ave-mujica-episode-3/)、[官方A03简介](https://anime.bang-dream.com/avemujica/story/)

<a id="a04"></a>

### A04 Acta est fabula.｜戏已落幕

**主要事件**

1. 接管对外活动的Mortis擅长节目和社交，乐队气氛看起来变好了。其他成员认可这种变化，祥子却越来越不安。
2. 排练暴露关键问题：Mortis不会像睦一样弹吉他。舞台角色与音乐能力无法直接互相替代。
3. Mortis向祥子说明自己与睦的区别，并把睦的退缩与祥子施加的压力联系起来；祥子面对的已经不是简单的排练问题。
4. 成员对能否继续巡演失去共识。Mortis愿意学习，也想保住乐队，但不能立刻补上演奏与信任的缺口。
5. Ave Mujica在巡演中途宣布解散。Mortis原想保护睦与归属，最终却面对归属一起失去的局面。

**名场面短引**：Mortis「ぜ～んぶ弾けな～い！」——“全都不会弹！”轻快语气和排练危机之间的反差，是这句的重要性。[短句与场景](https://japanese50sounds.com/en/anime/ave-mujica/zenbuhikenai.html)、[A04剧情核对](https://doublesama.com/bang-dream-ave-mujica-episode-4/)

<a id="a05"></a>

### A05 Facta fugis, facienda petis.｜逃离过去，追求未来

**主要事件**

1. 解散后众人分散回各自生活。若麦继续争取曝光，海铃回到其他工作；初华想留住祥子，祥子却从她家搬走、断开联系。
2. 祥子一度回到父亲那里，后来接受祖父安排回丰川家。她的住处和经济条件发生变化，但失去乐队的问题没有因此解决。
3. 灯持续在意M13那句祝福，以纸条询问祥子自己的幸福。祥子被触动，却没有马上向她敞开。
4. 爱音陪灯寻找祥子，两人来到丰川宅；灯在钢琴前再次提出一起做音乐的愿望。
5. 爽世因睦的缺席而探望，发现Mortis陷入恐慌：她无法让睦醒来，希望爽世帮忙。

**对白要点〔转述〕**：灯把“祝你幸福”反问回祥子身上——她真正关心的是祥子现在好不好。Mortis则请求把睦找回来。

**结果**：MyGO开始主动介入旧友的困境；祥子已回丰川家，不能在后续所有集数继续固定描写她住在旧房子。[A05解散后状态](https://doublesama.com/bang-dream-ave-mujica-episode-5/)、[A05场景记录](https://anitubu.com/archives/post-87493.html)

<a id="a06"></a>

### A06 Animum reges.｜控制你的心

**主要事件**

1. 祥子没有接受灯重新一起做音乐的邀请。另一边，爽世把Mortis的状况带到MyGO成员面前。
2. 乐奈很快注意到睦与Mortis的区别，与Mortis产生交流；她的吉他也成为唤起睦反应的契机。
3. 睦重新出现，却不能接受Mortis替自己做过的决定。两者在控制身体和未来选择上冲突，情绪失控被路人拍摄传播。
4. 立希质问海铃对Ave Mujica究竟是否在乎。海铃惯用的职业距离开始被挑战。
5. 祥子试图否认自己与旧团、新团和睦的问题有关。Mortis透露父亲住处，爽世前去后得知当初退队的现实缘由。

**对白要点〔转述〕**：乐奈辨认出眼前不只是同一种状态；爽世开始从责怪祥子转向追问她究竟经历了什么。

**信息变化**：本集之后，不能再让爽世像M08时一样完全不知道祥子的困境；但也不能让所有路人都知道家庭秘密。[A06事件参考](https://doublesama.com/bang-dream-ave-mujica-episode-6/)、[官方A06—A07简介](https://anime.bang-dream.com/avemujica/story/)

<a id="a07"></a>

### A07 Post nubila Phoebus.｜阴云之后是太阳

**主要事件**

1. 爽世找到祥子，要求她直面睦和当年的裂痕，把她带到睦家。祥子终于没有继续逃开。
2. Mortis起初阻止祥子见睦。祥子的等待、解释，以及爽世和立希的参与，让旧团的误解有机会被说出来。
3. 祥子补充睦当年那句“不快乐”的背景：睦对自身演奏的不满意，不等于CRYCHIC对她没有意义。
4. 灯拿出与当年相遇有关的文字和音乐。爱音支持旧成员再演奏一次，CRYCHIC五人短暂重聚，演奏《春日影》等承载旧日记忆的音乐。
5. 对MyGO一侧而言，这次演奏让旧伤得到回应，不代表放弃眼前的新团。海铃旁观后产生强烈的归属渴望，向祥子和睦提出复活Ave Mujica。

**对白要点〔转述〕**：本集回应的是“我们曾经一起拥有的东西是真的”；它与“必须恢复原来的乐队”不是同一个承诺。

**易错点**：一次重聚演奏不等于CRYCHIC正式重启；Mortis也没有在本集被永久消除。[A07剧情参考](https://doublesama.com/bang-dream-ave-mujica-episode-7/)、[官方后续剧情说明](https://us.oricon-group.com/news/3495/)

<a id="a08"></a>

### A08 Belua multorum es capitums.｜多头之兽

**主要事件**

1. 海铃的复团邀请没有立即成功。立希指出她长期保持可进可退的距离，很难让别人相信她真把某支乐队当成自己的归属。
2. 海铃谈到早期乐队经历：自己以为是在帮助伙伴，却遭遇排斥。这解释了她后来不断参与支援、避免深入介入的处事方式。
3. 睦希望回到CRYCHIC；Mortis则认为Ave Mujica关系到自己的存在。祥子发现两者的愿望并不相同。
4. 若麦与睦母亲森美奈美谈话。母亲把睦的表现与演技、才能联系起来，使若麦同时感到震动、嫉妒和不安。
5. 海铃继续联系若麦并帮助Mortis练吉他。重组Ave Mujica开始从一句愿望变成实际行动。

**对白要点〔转述〕**：海铃承认自己也想成为真正属于某个乐队的人；Mortis希望自己的存在获得承认，而不仅是等待睦回来后被丢弃。

**注意**：母亲对睦的说法是人物立场，不是全知旁白；不能据此断言睦的一切痛苦都是演戏。[A08分集参考](https://doublesama.com/bang-dream-ave-mujica-episode-8/)

<a id="a09"></a>

### A09 Ne vivam si abis.｜若你离去，我不愿独活

**主要事件**

1. 祥子为了回应睦的愿望，主动提出复活CRYCHIC。这与她此前拒绝回头的立场形成逆转，也牵动爱音和MyGO的现有关系。
2. 初华得知后感到自己与Ave Mujica被排除在祥子的未来之外。她找事务所寻求重组支持，未能如愿。
3. 与睦的接触进一步刺激初华，她脑中出现伤害睦的画面，随即被自己的念头吓到。**动画没有把推落睦呈现为实际发生的事件。**
4. 睦与Mortis在内心舞台争执，睦坠落、消失。Mortis害怕自己也失去存在的位置，开始模仿睦。
5. 多人在RiNG聚到一起，复活CRYCHIC还是Ave Mujica的诉求直接冲突。爽世强调不能把时间倒回去，海铃也明确表达自己想要Ave Mujica。

**对白要点〔转述〕**：争执中的每个人都在说“为了谁”，却未必真正听见那个人的愿望。Mortis模仿睦，体现的是生存恐惧，不是又有一个外部人物出现。

**叙事边界**：内心舞台的“死亡”不能写成现实肉体死亡；初华的冲动也不能记成已实施的伤害。[A09场景核对](https://animecorner.me/ave-mujica-episode-9-everything-is-falling-apart/)、[A09内心舞台参考](https://doublesama.com/bang-dream-ave-mujica-episode-9/)

<a id="a10"></a>

### A10 Odi et amo.｜我恨，也爱

**主要事件**

1. 若麦识破Mortis在扮演睦，冲突把Mortis逼到崩溃；MyGO成员介入，祥子无法接受眼前的状况而离开。
2. 初华写下与祥子有关的歌词，若麦带着她和这些文字去找祥子，要求祥子面对自己组起这支乐队之后留下的责任。
3. 祥子重新作曲并答应让Ave Mujica再度演出。重聚地点是RiNG，规模与此前巡演不同。
4. 《Imprisoned XII》《Crucifix X》的演出中，Mortis与睦在内心舞台相遇、和解并消隐；若麦也表达了自己对才能既嫉妒又被吸引的复杂心情。
5. 演出后，祥子的祖父出现，以“初音”称呼大家一直认识的初华，身份秘密正式被揭开。

**对白要点〔转述〕**：若麦并非只想借睦成名，她也被睦与Mortis的表达打动；祥子重新组团的决定带有被追问责任后的迟疑，并非所有问题已解决。

**本集悬念**：“初音”不是随口昵称，而是A11的重要身份线索。[A10演出与结尾参考](https://doublesama.com/bang-dream-ave-mujica-episode-10/)、[Mortis与若麦场景分析](https://note.com/gyozapouch/n/n9b6dbdd93b3a)

<a id="a11"></a>

### A11 Te ustus amem.｜燃尽仍爱你

**主要事件**

1. 本集通过独白、回忆与剧场化呈现，交代主唱“初华”的真实身份是三角初音；她有一个真正名叫初华的妹妹。
2. 姐妹成长在岛上。初音是丰川定治与别墅管理员所生的女儿；定治是丰川家的婿养子，母亲担心秘密影响他的地位。初音不能像妹妹那样自由地接近来访的祥子。
3. 妹妹生病时，初音代替她与祥子相处；短暂的共同经历对初音极其重要，也成为她后来执念的起点。
4. 初音离开岛屿赴东京，使用妹妹初华的名字进入演艺圈、加入sumimi。她与祥子的父亲清告有过接触；清告曾为她向定治交涉。
5. 回到现在，定治要求祥子去瑞士并远离初音。初音离开东京回岛上，乐队刚恢复又面对失联。

**对白要点〔转述〕**：初音承认自己借用了妹妹的名字和人生方向。该揭露也改变了“她与祥子拥有全部童年回忆”的理解。

**身份边界**：初音是祥子祖父的女儿，从亲属关系看是祥子的姨辈；初音与妹妹初华是同母异父的姐妹。“没有丰川本家血统”不等于与祥子没有亲缘。姐妹是现实中的不同人物，不是睦／Mortis式的内心人格。出身秘密与父亲失势有关联，但不能自行补成“初音策划了所有财务事件”。[A11身份叙述参考](https://doublesama.com/bang-dream-ave-mujica-episode-11/)、[家族与姐妹背景补充](https://www.sina.cn/news/detail/5144019823231586.html)、[A11—A12关联核对](https://finalweapon.net/2025/03/20/ave-mujica-the-die-is-cast-episode-12-review-spoilers/)

<a id="a12"></a>

### A12 Fluctuat nec mergitur.｜虽受风浪，不曾沉没

**主要事件**

1. 祥子没有服从出国安排，而是去岛上寻找初音。她不再只接受祖父为自己决定下一步。
2. 初音亲自坦白身份与欺骗。祥子逐一确认记忆：许多童年相处属于妹妹，真正与初音共有的经历有限，但现在一同经历过的事情并不因此消失。
3. 两人返回东京。祥子向祖父表明自己的选择，再次离开丰川家的安排，与初音一起生活。
4. 对外，“三角初华”的身份继续被使用。身份秘密没有在全社会公开，也不能假定所有团员都知道详情。
5. 祥子写信回应灯，承认对MyGO造成的困扰与灯给予的支持，并重新接手Ave Mujica的未来，向事务所争取继续活动。

**核心短引**：祥子「わたくしが神になります」——“我要成为神。”这是她拒绝把命运交给别人、决意承担乐队的戏剧化宣言，不能据此把日常祥子写成自称神明的人。[短句核对](https://japanese50sounds.com/en/anime/ave-mujica/kamininarimasu.html)、[A12剧情参考](https://finalweapon.net/2025/03/20/ave-mujica-the-die-is-cast-episode-12-review-spoilers/)、[童年记忆区别](https://doublesama.com/bang-dream-ave-mujica-episode-12/)

### A13 Per aspera ad astra.｜循此苦旅，以达天际

**主要事件**

1. 结局以两支乐队的舞台为中心。MyGO继续自己的音乐，《聿日箋秋》《焚音打》等内容延续灯以文字连接人与现在的方向。
2. Ave Mujica恢复演出，通过《八芒星ダンス》《顔》《天球のMúsica》等歌曲及戏剧段落，把假面、秘密与重新选择彼此的主题带回舞台。
3. 祥子与“初华”经历了真相之后仍继续同行；对外舞台并没有变成向观众公开全部私人经历的说明会。
4. 睦仍参与演奏，结尾保留与Mortis有关的映像。不能把前面的内心消隐直接解释为肉体死亡，也不宜简单宣布所有人格与心理问题已经治愈。
5. MyGO向前走，Ave Mujica也能够继续站在一起；然而家族、身份与内在矛盾并非每一项都获得彻底解决。

**对白要点〔转述〕**：季节和身边景色已经改变，经历过的事情没有被抹去。官方简介以季节变化概括结尾；本集的重要表达更多由演奏、舞台动作和歌曲承担，不另编一条“全员毕业宣言”。[官方A13简介](https://anime.bang-dream.com/avemujica/story/)、[A13演出结构](https://doublesama.com/bang-dream-ave-mujica-episode-13/)、[曲目所属集数](https://zh.wikipedia.org/wiki/BanG_Dream!_Ave_Mujica)

## 对角色聊天尤其重要的事实边界

1. **祥子不是永远只会拒绝过去。**她在不同阶段有逃避、拒绝、面对、重新演奏甚至想重启旧团的变化。引用M08的话时，不能抹掉A07—A12的发展。
2. **祥子并非一直掌控全局。**揭面、睦的状态、解散和家族秘密都曾让她失去控制；舞台上的指挥者形象不能覆盖全部生活。
3. **爽世在续篇里已经有变化。**她照顾Mortis、追查祥子处境并促成面对旧伤，不能永久停留在M08恳求复团的状态。
4. **爱音不是旧团的替代零件。**M09的伤害和M10的选择都建立在这点上；A07支持旧友重聚，也不是答应拆掉MyGO。
5. **乐奈与祥子并非到结局还绝无接触。**续篇已经有跨团相处，早期“不认识”的关系描述不能无限沿用。
6. **睦、Mortis与舞台角色同名的问题需要看语境。**Mortis既是乐队舞台名，也用于称呼内心角色；并非每次出现这个名字都意味着人格切换。不要用戏剧描写给现实人群作诊断。
7. **“初华”在后期有公开身份与真实身份之分。**日常其他成员仍可能叫她初华，不应让机器人在每段闲聊里主动揭她的秘密。
8. **名言有触发场景。**“为什么要演奏春日影”“把人生交给我”“我要成为神”是特定矛盾或决意的高点，不适合拿来填充问候、天气和普通关心。
9. **本项目同人设定独立于剧情资料。**若保留祥初恋人设定，应把它标为项目采用的关系版本，而非用本参考文档反向证明动画已经明确确认。
